# 0003. Репозиторий публичный

Дата: 27.09.2026
Статус: принято Настей

## Контекст

По стандарту репозитории приватные, публичным репозиторий становится по прямому решению
Насти. На бесплатном тарифе GitHub Pages и защита веток работают только у публичного
репозитория (https://docs.github.com/en/get-started/learning-about-github/githubs-plans).
В проекте template-video-renderer защита `main` на приватном репозитории 16.09.2026 упала
с ошибкой `403`.

## Решение

Репозиторий `landing-voda-danang` публичный с первого коммита.

Заказчик вымышленный, чужого кода и данных нет. Телефоны реальных дистрибьюторов из полевых
заметок в репозиторий не попадают: копия заметок в `docs/` их не содержит, на сайте стоят
заглушки.

## Что это меняет

1. Защита `main` и Pages включаются без платного тарифа.
2. Всё, что попадает в коммит, видно всем. `.env` закрыт `.gitignore` первым коммитом,
   хотя секретов у статического сайта нет.
