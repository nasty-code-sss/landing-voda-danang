# 0006. Язык по браузеру в корне и флаги в переключателе

Дата: 28.09.2026
Статус: принято Настей

## Контекст

По ТЗ корень `/` показывал окно выбора из трёх кнопок, язык браузера только подсвечивал
подходящую. Основание было такое: Google не советует автопереадресацию по языку.
Переключатель в шапке подписывал языки самоназваниями и без флагов.

Настя посмотрела выпущенный `v0.1.0` и решила иначе: окно выбора при первом заходе лишнее,
язык должен определяться сам, а переключатель должен быть выпадающим списком с флагом и кодом.

Проверка по первоисточнику показала, что основание в ТЗ было записано строже, чем у Google.
В [Managing multi-regional sites](https://developers.google.com/search/docs/specialty/international/managing-multi-regional-sites)
сказано: «Avoid automatically redirecting users from one language version of a site to a
different language version of a site», то есть речь о переадресации между языковыми версиями.
В [Localized versions](https://developers.google.com/search/docs/specialty/international/localized-versions)
автопереадресующий корень назван обычным местом для `x-default`: «Consider adding a fallback
page for unmatched languages, especially on language/country selectors or auto-redirecting
home pages».

## Решение

1. Корень открывает язык, выбранный раньше вручную, иначе первый подходящий язык браузера,
   иначе `languages.default`. Языковые версии `/en/`, `/vi/`, `/ru/` не переадресуют никуда.
2. Без JavaScript язык браузера на статическом хостинге не узнать, поэтому ссылки на все
   языки в корне остаются.
3. В шапке выпадающий список на `<details>`: флаг и код текущего языка, в списке флаг и код
   каждого. Самоназвание языка скрыто для глаз и читается экранным диктором.
4. Флаг задаётся в конфиге для каждого языка (`languages.flags`). Язык не равен стране,
   поэтому страна флага это решение, а не вывод из кода языка: для английского стоит `gb`.
5. Флаги взяты из [flag-icons](https://github.com/lipis/flag-icons) (MIT), лежат файлами
   в `src/shared/ui/flags/` вместе с лицензией и встраиваются картинкой `data:`: внутри SVG
   есть свои `id`, и при вставке одного флага дважды прямо в разметку они бы повторились.

## Что это меняет

1. Сценарии ТЗ 4 и 9 переписаны под автоопределение, добавлены e2e на список языков.
2. Новый язык требует строку в `languages.flags` и файл флага, иначе сборка останавливается.
