# Mỹ Water: лендинг доставки воды в Дананге

Иностранец в Дананге на своём языке понимает, сколько стоит первый заказ с залогом, и одним нажатием отправляет готовый заказ воды в свой мессенджер.

Демонстрационный проект. Служба доставки вымышленная, контакты на сайте заглушки.
Цены, залог и минимальный заказ взяты из живого заказа воды в районе Нгуханьшон
и из разбора девяти местных продавцов.

## Что уже работает

- Пять языковых версий по своим адресам: `/en/`, `/vi/`, `/ru/`, `/ko/`, `/zh/`. Корейский
  и китайский выбраны по гостям Дананга: Корея и Китай первые два места. Корень сам открывает язык
  браузера, выбранный вручную язык запоминается и важнее. В шапке выпадающий список
  языков с флагом и кодом.
- Страница целиком: первый экран, как это работает, залог с примером расчёта, карточки цен,
  конструктор заказа, доверие, помпа, зона и часы доставки со схемой, блок для хозяев квартир,
  частые вопросы, финальный призыв, подвал с блоком владельца на вьетнамском.
  На телефоне снизу полоса «Заказать воду» с суммой заказа.
- Конструктор заказа: первый заказ или обмен бутылей, бренд, количество, помпа,
  геолокация или адрес, день и оплата. Итог с залогом считается сразу.
- Готовое сообщение уходит в WhatsApp, Telegram, Zalo, в корейской версии ещё в KakaoTalk,
  в китайской в WeChat, и одновременно копируется в буфер. У WeChat ссылки на чат нет,
  поэтому под кнопкой раскрываются WeChat ID и QR-код.
  Если язык страницы не вьетнамский, ниже идёт тот же заказ по-вьетнамски для оператора.
- «Повторить прошлый заказ» для постоянных покупателей и «Забыть мой заказ».
- «Сегодня» закрывается по времени Вьетнама, а не по часам телефона.
- QR-наклейка `/?mode=refill&brand=biwa` открывает обмен бутылей на запомненном языке.
- SEO: canonical, hreflang, карта сайта, Open Graph с картинкой на каждом языке, LocalBusiness.
- События аналитики в очереди страницы `dataLayer`. Сервис аналитики не подключён.
- Страница документов: политика конфиденциальности, условия доставки, порядок жалоб.

## Запуск

Нужен Node.js 24.

```
npm install
npm run dev          разработка, http://localhost:4321/landing-voda-danang/
npm test             модульные тесты
npm run check        проверка типов
npm run build:dev    сборка в dist/
npm run preview      раздать собранный dist/
```

## Проверки

```
npm run format:check   формат (Prettier)
npm run lint           линтер и запрет комментариев
npm run secrets        сканер секретов
npm run test:coverage  модульные тесты с порогом покрытия
npx playwright install chromium
npm run build:prod
npm run e2e            20 сценариев ТЗ и блоки страницы в браузере
npm run smoke          страницы отвечают, картинки превью и карта сайта на месте
npm run lighthouse     Lighthouse на телефоне и объём JavaScript
```

Для e2e, smoke и Lighthouse нужны `E2E_BASE_URL` и `E2E_SITE_DIR` (см. `.env.example`):
положить их в `.env` или задать в командной строке. Например, `E2E_SITE_DIR=dist`
и `E2E_BASE_URL=http://127.0.0.1:4322/landing-voda-danang/` поднимут собранный `dist/`
и прогонят тесты по нему.

## Конфигурация

Всё, что заказчик меняет без вёрстки, лежит в `config/base.yml`:

- `brands`: бренды, цены, залог, краник. Бренд с `example: true` идёт в пример залога.
- `pumps`, `payments`, `order`: помпы, способы оплаты, минимальный и максимальный заказ.
- `contacts`, `warehouse`, `owner`: телефоны, мессенджеры, адрес склада, реквизиты для подвала.
- `delivery`, `zone`: часы, дни, граница «сегодня», районы с прежними названиями.
- `trust`: обещания блока доверия. Выключенный флаг убирает пункт с сайта и из ответов.
- `messengers.order`: порядок кнопок мессенджеров на каждом языке.
- `messengers.links`: адреса чатов, `{contact}` заменяется значением из `contacts`.
- `contacts.kakaotalk`: ID канала KakaoTalk, он начинается с `_`, виден в адресе канала.
- `contacts.wechat` и `contacts.wechat_qr`: WeChat ID и то, что зашито в «Мой QR-код»
  в WeChat: считать сканером QR с картинки этого кода и вставить как есть.
- `languages.flags`: флаг страны у каждого языка в переключателе, файлы флагов лежат
  в `src/shared/ui/flags/`.

Поменять цену: исправить `price` у бренда и пересобрать. Новая цена появится на карточке,
в конструкторе и в сообщении, у бренда примера ещё и в примере залога. Строка «от ...»
на первом экране и на картинке превью берёт самую низкую цену прайса.

Отличия контуров в `config/dev.yml`, `config/stage.yml`, `config/prod.yml`.
Какой контур собирается, задаёт переменная `APP_ENV`. Тексты лежат в `i18n/*.json`.

## Переводы

Вьетнамская, корейская и китайская версии до боевого запуска вычитываются носителями языка.

Новый язык: словарь `i18n/<код>.json` со всеми ключами английского, код в `languages.supported`,
флаг в `languages.flags` и файл флага в `src/shared/ui/flags/`, порядок мессенджеров
в `messengers.order`. Если в языке есть знаки, которых нет в Manrope, для картинки превью
нужен пакет шрифта в `design.share_image.script_fonts`.
